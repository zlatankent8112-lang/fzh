➕ Bulk Create Fee Structures

Create multiple fees at once for a specific educational level or grade

💡 How it works:
1. Common Settings: Set defaults for all fees (academic year, term, frequency, level)
2. Individual Fees: Each fee can override term & frequency if needed
3. Examples:
   • Registration Fee → Override frequency to "One-Time", check Optional
   • Swimming → Override term to "Term 1", check Optional
   • Tuition → Use common settings (All Terms, Per Term), keep Mandatory
   • Coding/Robotics → Check Optional (parent can choose)
4. Flexibility: Mix mandatory fees (Tuition, Lunch) with optional activities (Swimming, Coding) in one go!
